# Benchmark v1 数据准备与校验

## 范围

使用用户提供的 `data.xlsx` 和 `sales` 图片制作待核查评估集。用户说明这批数据未用于微调训练，尚未独立核实训练清单。原始文件不修改，图片和逐行标注不提交到公开 Git；本地结果保存在已忽略的 `data/benchmark_v1/`。

该版本准备数据，不运行 OCR 或 Agent，也不提供任务成功率。异常故障注入、多轮记忆、图表与报告任务将另外补充。首批 20 个任务只涵盖查询统计和无匹配结果。

## 程序校验结果

- 500 张已标注图片均存在且通过图片格式验证，4,872 条明细；无未标注图片。
- 106 条税率为空、100 条金额为空，涉及 14 张图。空值不替换为零。
- 3,149 个金额标签为 Excel 公式，涉及 329 张图。保存公式及缓存值；不把缓存值自动认定为金标准。
- 453 行数量乘单价与金额不一致，涉及 50 张图。可能来自折扣等原因，需核查原图，不能自动重算。
- 962 行与同图较早行完全相同，涉及 337 张图。保留重复行和次数，不能直接去重。
- 没有发现文件哈希完全相同的图片；这不能证明没有视觉近似图片或模板相似性。

提示类别可重叠，数量不能相加当作错误数。图片格式验证不能证明内容清晰或标注正确。未逐图人工复核。

## 样本与任务

OCR 样本保存图片相对路径、SHA-256、尺寸、原始标注、规范化值和 Excel 行号，全部标记为 `pending`。只统一数值格式和明确日期格式，不翻译名称、不补字段、不去重、不改金额。

Agent 夹具按文件名顺序选择 20 张可读取、字段完整且不含公式标签的图片，共 204 行。单据存在折扣或重复行时保留原始金额和重复次数，仍需用户核查。这只是便于复现的起始子集，未经随机/分层抽样，不能代表全数据质量。

生成 19 个关键词全量统计任务和 1 个无匹配任务。预期金额用 Decimal 从夹具标注计算，保留参与计算的 Excel 行号；另用独立内存 SQLite 的 LIKE/SUM 查询核对 20 个任务，金额和行数均一致。隔离夹具设为 confirmed 只是评估前置条件，不代表真实生产确认状态，不写入生产数据库。

单元测试共 23 项通过，新增测试验证折扣金额保留、空值、无效字段提示、重复行保留以及中文日期/百分数规范化。没有实际模型质量、延迟或费用测量。

## 复现

准备脚本的额外读取依赖为 `openpyxl` 和 `Pillow`，只用于离线数据准备。可使用已配置的 bundled Python；不增加线上 Agent 依赖。

```powershell
python evals/prepare_benchmark.py --source '你的数据目录' --output data/benchmark_v1
python -m pytest tests -q
```

已有人工核查意见时，重新运行请使用新的输出目录，避免覆盖核查清单。规范化缓存值不重新计算 Excel 公式；缓存可能过期。

## 人工核查入口

本地 `data/benchmark_v1/REVIEW.md` 汇总核查原则和文件入口。`review.csv` 包含图片名、Excel 行号、提示类型及 review_decision；`task_review.csv` 包含问题、预期金额和来源行号。核查意见可填写“确认原值 / 应修正为… / 暂不能确认”。

建议先检查公式金额，再确认空字段的评分口径；最后核对首批任务的问题和预期答案。人工核查完成前不将这些候选任务宣称为审核通过的 benchmark。之后划分调参集和最终测试集时以图片分组，并考虑模板相似性，避免同图不同行跨集合。
