本批验证真实 HTTP/SSE、SQLite、工具执行和少量真实 DeepSeek 调用。所有发送给模型的销售数据均为合成数据；没有发送原始发票图片或校对标签。保留开发过程中失败的 JSON，不将调试用例称为独立测试集。

## 实现与质量意义

- SSE 同步生成器在工作线程执行，避免模型/SQLite 等待阻塞 ASGI 事件循环；显式关闭生成器处理客户端断开，释放会话锁。
- 只读临时失败要求原条件重试一次，参数错误先修正；写入、确认、生成操作失败仍停止核查，避免重复副作用。
- 对“报告/图表已生成”等完成措辞检查本轮对应工具成功返回及文件存在；没有证据时只允许一次纠正，重复虚构则返回未生成。该规则按有限中文措辞匹配，不保证拦截所有变体，也不验证最终回答中的每个路径与工具路径完全一致。
- 报告单据数与金额统一使用年份及 confirmed 范围；图表和报告使用唯一文件名，避免覆盖旧统计快照。图表参数错误、非正饼图数据会明确拒绝；保存/嵌入异常释放图形资源及中间 PNG，报告提示图表缺失。

额外纠正最多增加一次模型调用；未建立可比 token 成本或端到端延迟分布，不能声称成本改善。主要收益是减少错误完成声明、会话竞争和阻塞。

## 未覆盖与已知边界

- 原 OCR `/models` 可用性探测返回 ConnectionError。真实 OCR 字段质量、识别时延以及图片到报告全流程尚未验证；不能用故障替身或备用模型结果代替原微调模型质量。
- 最后一轮真实 DeepSeek 的非法参数、永久读取故障、OCR 离线第二次用例没有进入工具：分别 Request timed out、Connection error、Connection error。运行护栏如实停止，无业务成功声明，但这三项目标未完成验证。保留 `2026-10-02-live-recovery-final.json`，不通过反复重跑覆盖失败。
- 单进程会话锁不适用于跨进程；没有生产规模负载、长时间稳定性、真实模型高并发或 provider 限流测量。
- 报告分组表目前截取前 15 组；大规模报告完整性需要单独扩展。图表网页展示与报告下载 UI 未在本批验证。
- 固定用例已参与调试，正式能力评估需增加未用于调试的题目与不同数据；这里不报告泛化准确率。
- 初期 HTTP 基线夹具有 SQLite 连接未关闭导致临时目录清理失败，已修正。早期总耗时阈值在负载变化时误判并发，后续使用模型等待区间重叠判断；保留原文件以便审计。

## 复现

在仓库目录使用配置好依赖和 DeepSeek 的 Python 执行：

```powershell
python -m pytest -q
python evals/http_runtime_probe.py --output data/http.json --soak-requests 2000
python evals/live_recovery_probe.py --output data/recovery.json
python evals/known_gap_benchmark.py --output data/known-gaps.json
python evals/context_preference_probe.py --output data/preferences.json
python evals/artifact_flow_probe.py --output data/artifact-flow.json --artifacts-root data/artifact-flow-new
python evals/render_artifact_reports.py --manifest data/artifact-flow.json --output data/render.json
```

artifact-flow 每次使用新的产物目录，避免旧文件污染评分。渲染需要本机 Word、pywin32 和 pypdfium2；测试服务与数据库隔离，不修改正式业务数据。
