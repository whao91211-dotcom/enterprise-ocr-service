# 任务与运行保护基线：2026-09-30

## 评估边界

用户确认现有发票校对数据按实际开具内容保留，不因乘法不一致、空字段或重复行自动修改。接受现有数据不意味着已经独立逐图重标。公式、缓存值、图片哈希与 Excel 行号仍保留用于追溯。

本地任务定义共有 35 个场景：20 个查询统计任务、5 个上下文/偏好场景、10 个故障场景。来自现有候选夹具的 20 张图、204 行用于 SQL 查询标准答案检查；多轮与故障刺激是另行构造的。不是 35 个真实模型任务全部完成后的成功率。

## 离线结果

| 指标 | 通过 / 用例数 | 测量对象 |
| --- | --- | --- |
| SQL 工具与标准答案一致 | 20/20 | 真实 SQL 工具；直接提供参数，不评模型选工具 |
| 必要上下文传递 | 4/5 | 实际流式循环传给模型的消息；不评模型理解 |
| 运行保护目标 | 5/10 | 实际循环与错误处理；模型请求由替身控制 |

SQL 任务包含 19 个关键词总额/行数任务和 1 个无匹配任务，夹具另加一条待确认控制记录，避免误计入统计。偏好用例只检查偏好文本与优先级规则进入系统提示，不证明跨会话存取或模型遵循（已有记忆测试另行验证）。

运行保护通过项：OCR 离线不会创建文档；普通工具异常、未知工具、非法分组和错误参数类型能返回错误。恢复策略尚未由真实模型测试。

可复现缺口：

1. 14 条历史保留最近 10 条，最早的必要年份被丢弃。
2. 相同失败调用重复 8 次才由轮数上限停止，未达到候选目标最多 2 次。
3. 两个失败调用交替 8 次才停止，未达到候选目标最多 4 次。
4. 每轮 3 个调用时累计 24 次才停止，未达到候选总预算 8 次。当前上限是轮数。
5. 工具与模型阻塞注入均未在 2 秒诊断预算内返回，由评估子进程管理器终止。

这些阈值是 benchmark 的改进目标，不是现有实现的保证。2 秒用于快速暴露循环缺少统一调用预算，不是生产 OCR 超时建议；未测试 httpx 或 DeepSeek SDK 内置超时，不能据此宣称真实网络调用永远不超时。子进程导入完成、阻塞调用开始之后才计时；初始化失败另记 not_run。

离线加载时跳过未使用的旧版 AgentExecutor 导入，避免其 Transformers 环境扫描；真实 `run_agent_events` 与工具代码没有替换。仅替换模型响应及故障边界。首次环境导入诊断不纳入服务性能结论。

## 少量真实 DeepSeek 诊断

只发送合成销售数据：2024 年甲公司 100、乙公司 200，2025 年乙公司 900。没有发送用户提供的发票图片或标注。

| 任务 | 预期 / 回答金额 | 耗时 | 工具行为 |
| --- | --- | ---: | --- |
| 2024 年甲公司销售额 | 100 / 100 | 7.295 秒 | rag_summarize，keyword=甲公司，year=2024 |
| 那乙公司呢？ | 200 / 200 | 2.445 秒 | 保留2024年，keyword改为乙公司 |
| 2024 年总销售额 | 300 / 300 | 2.349 秒 | 全量统计，year=2024 |

逐例查看工具参数、结果和最终回答后，3 个诊断任务均满足金额与年份要求。每例只运行一次，不是代表性正确率或稳定延迟估计。先前相同三个合成任务也曾正确，本轮没有证明准确率提升；传输配置和运行时条件不同，不作延迟前后比较。没有测量实际 token 或费用。

评估专用模型实例设置请求 timeout=20 秒、max_retries=0，避免诊断耗时失控；线上配置没有修改。此 SDK 评估设置与上一节“通用循环对任意阻塞调用无预算”的故障注入分别报告。
